# PowerBI-Social-Media-Dashboard
Social Media Performance Dashboard created by using PowerBI.

## 📄 Project overview 
This project focuses on analyzing social media performance across multiple platforms to understand audience engagement, content effectiveness, and growth trends.
The analysis helps identify which platforms, content types, and posting times perform best and supports data-driven decision-making for social media strategy.
The dashboard is divided into three pages to provide a clear summary, detailed analysis, and time-based and location-based insights.

## 🎯 Objective of the project
The main objectives of this project are:
* To analyze overall social media performance.
* To measure engagement across different platforms.
* To identify top-performing content and posts.
* To study trends over time (daily / monthly).
* To provide insights for improving content strategy.

## 📊 Key KPIs
* Total Posts
* Total Engagement
* Average Engagement Rate
* Total Views
* Total Likes
* Total Comments
* Total Shares
* Click-Through Rate (CTR)
* Engagement per Post

## 📃 Dashboard Pages
### 📌 Executive Summary : 
* Shows overall social media performance at a high level.
* Displays total posts, total engagement, views, likes, comments, and shares.
* Shows daily engagement trends over time.
* Provides engagement distribution by region.
* Helps stakeholders quickly understand overall performance .
